# 🤖 Portfólio QA - Automação com Playwright + Python

Projeto de testes automatizados E2E no site SauceDemo.

### ✅ Testes Implementados
- **test_login_com_sucesso**: Valida login com credenciais válidas
- **test_login_com_erro**: Valida mensagem de erro com credenciais inválidas  
- **test_adicionar_no_carrinho**: Valida adição de produto ao carrinho

### 🚀 Tecnologias
- Python
- `Playwright`
- Pytest

### ▶️ Como rodar
```bash
pip install playwright pytest
playwright install
python test_qa_portfolio.py
